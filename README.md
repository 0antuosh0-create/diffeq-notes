# جزوه معادلات دیفرانسیل | نیم‌ترم دوم

پورتال مطالعه تعاملی درس معادلات دیفرانسیل — شامل جزوه درسی، فرمول‌ها، خلاصه فصل‌ها، جدول انتگرال‌ها و آمادگی امتحان.

🌐 **نسخه زنده:** https://0antuosh0-create.github.io/diffeq-notes/

![وضعیت استقرار](https://github.com/0antuosh0-create/diffeq-notes/actions/workflows/deploy.yml/badge.svg)

## ✨ امکانات

- 📖 **جزوه کامل** — معادلات همگن، تغییر پارامترها، دستگاه معادلات و تبدیل لاپلاس
- 📝 **خلاصه فصل‌ها** — مرور سریع هر فصل
- 📋 **چیت‌شیت فرمول‌ها** — دسترسی سریع به فرمول‌های کلیدی
- 🧮 **جدول انتگرال‌ها** — با دسته‌بندی و جست‌وجو
- 🎓 **بخش آمادگی امتحان** — مهارت‌ها و تمرین‌ها
- 🔍 **جست‌وجوی سریع** — با `Ctrl + K` یا کلید `/`
- 🌙 **حالت تیره / روشن** — با ذخیره‌سازی خودکار
- ✅ **پیگیری پیشرفت مطالعه** — ذخیره‌شده در مرورگر (localStorage)
- 📐 **نمایش ریاضی با KaTeX** — فرمول‌های تمیز و دقیق
- 🇮🇷 **کاملاً فارسی و راست‌چین** — با فونت وزیرمتن

## 🚀 اجرا در محیط توسعه

پیش‌نیاز: **Node.js 20+** و **npm**

```bash
npm install
npm run dev
```

سپس مرورگر را روی آدرس نمایش‌داده‌شده (معمولاً `http://localhost:5173`) باز کنید.

## 📦 بیلد

```bash
npm run build
```

خروجی در پوشه `dist/` ساخته می‌شود. پروژه با `vite-plugin-singlefile` به‌صورت **تک‌فایل (`index.html` واحد)** بیلد می‌شود، پس برای استقرار روی هر هاست استاتیک کافی است.

پیش‌نمایش بیلد:

```bash
npm run preview
```

## 🌐 استقرار (GitHub Pages)

استقرار به‌صورت خودکار با GitHub Actions انجام می‌شود:

1. هر پوش روی شاخه `master` ورک‌فلوی `Deploy to GitHub Pages` را اجرا می‌کند (`.github/workflows/deploy.yml`)
2. پروژه بیلد شده و پوشه `dist/` روی GitHub Pages منتشر می‌شود
3. آدرس زنده: https://0antuosh0-create.github.io/diffeq-notes/

## 🗂️ ساختار پروژه

```text
src/
├── App.tsx               # کامپوننت اصلی و مدیریت نما
├── main.tsx              # نقطه ورود
├── index.css             # استایل‌ها (Tailwind)
├── types.ts              # تایپ‌ها
├── components/           # توپ‌بار، سایدبار، جست‌وجو، بلوک‌های ریاضی و...
├── content/              # محتوای درسی (ch3، ch5، ch6، خلاصه، انتگرال‌ها و...)
│   ├── ch3.ts
│   ├── ch5.ts
│   ├── ch6.ts
│   ├── courseSummary.ts
│   ├── integrals.ts
│   └── variation.ts
├── views/                # نماها: جزوه، چیت‌شیت، خلاصه، امتحان، انتگرال‌ها
└── utils/                # توابع کمکی
```
